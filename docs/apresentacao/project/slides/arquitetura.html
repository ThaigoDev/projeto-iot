Dispositivos

  • Atuador de irrigação

COMUNICAÇÃO

  • Eclipse Mosquitto
  • Tópicos por talhão
  • Last Will = offline

PROCESSAMENTO

Serviço central

  • Ingestão
  • Motor de regras
  • Automação

APRESENTAÇÃO

Dados e painel

  • SQLite (histórico)
  • REST + WebSocket
  • Painel web (Nginx)

Comandos de irrigação fazem o caminho inverso: serviço central → broker → atuador → válvula.

Quatro camadas. No campo, os dispositivos publicam via MQTT. O broker desacopla quem produz de quem consome. O serviço central processa, avalia e decide. A camada de apresentação persiste e entrega ao painel em tempo real por WebSocket. O caminho de volta leva os comandos de irrigação.
