11 · RESILIÊNCIA

Derrube um dispositivo ao vivo

# simula queda do gateway leste

docker stop agro-node-leste

# simula pane no atuador

docker stop agro-atuador-irrigacao

# religa tudo

docker compose start

Last Will do MQTT avisa na hora que o gateway caiu.

Fluxograma fica vermelho e um alerta crítico aparece no painel.

Comando sem resposta em 10 s vira alerta do atuador.

Recuperação automática ao religar, sem reiniciar nada.

Ótimo momento para demonstrar ao vivo. Parar um container simula a queda do hardware. O broker publica o Last Will, o painel mostra o gateway offline e o fluxograma marca a etapa em vermelho. Ao religar, o dispositivo se reconecta e tudo volta ao normal sozinho.
