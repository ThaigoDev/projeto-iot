12 · COMO EXECUTAR

Um comando para subir tudo

1

Subir os 9 containers

docker compose up -d --build

2

Abrir o painel

http://localhost:8080

3

Espiar as mensagens MQTT (opcional)

mosquitto_sub -h localhost -p 1884 -t "agro/#" -v

Para rodar basta Docker. Um único docker compose up sobe broker, serviço central, painel e os seis dispositivos simulados. O broker fica exposto na porta 1884 do host para quem quiser assinar os tópicos diretamente.
