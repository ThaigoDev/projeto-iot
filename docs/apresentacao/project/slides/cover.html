Apresentar o AgroSentinel: um sistema que monitora uma plantação talhão por talhão, mostra quais lavouras estão saudáveis e quais precisam de atenção, e acompanha o fluxo de dados de ponta a ponta. Todos os componentes físicos rodam simulados em containers Docker.
